# 🇮🇳 Tourism in India

A web-based tourism website designed to showcase the beauty, culture, heritage, and popular tourist destinations of India.

## 📌 About the Project

**Tourism in India** is a frontend web development project that provides users with information about different tourist destinations in India.

The website is designed with a simple, attractive, and user-friendly interface to help users explore different places and learn about Indian tourism.

## ✨ Features

* 🏠 Home Page
* 🇮🇳 About India
* 🗺️ Tourist Destinations
* 📸 Image Gallery
* 📝 Blog Section
* 📞 Contact Section
* 🌐 Easy Navigation
* 📱 Responsive Design
* 🎨 User-Friendly Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
